# SECon Main 2027 Robot

Robot programs for the Main team robot. This is the universal template for developing the robot and testing its libraries.

Include all libraries in the `include` directory.

## Libraries

- control: Used for setting control levels for the motor drivers from the Crotch Pico
- imu: Used for communicating back and forth with the IMU
- bus: High level control for initializing and communicating over I2C
